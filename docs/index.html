PubMed SLR ScreeningTrialMind（npj Digital Medicine 2025）の検索・スクリーニング・抽出を Claude Code で組み直したワークフロー

系統的文献レビュー（SLR）の検索・タイトル抄録スクリーニング・研究特性の抽出を、Claude Code の subagent・skill・hook・MCP で回したときの結果の画面です。教育と手法の検証用で、業務の代わりではありません。

eval-3：原著と比べる

人の判断を挟まない、原著と同じ流れ。検索 Recall、Recall@20・@50、抽出の Accuracy と、論文ごとの判定・抽出した値。

eval-2：人が入る流れ

2体の screener が基準ごとに判定し、割れた論文だけを人が判断する流れ。概要・要人判断・結果の3つの画面。

公開用の見本です。抄録の本文と逐語引用は伏せています（判定・スコア・抽出した値・人の判断はそのまま）。抄録は各論文の PMID のリンクから PubMed で読めます。画面は読むだけで、判断や採点は変えられません。

Public sample of the reports: abstracts and verbatim quotes are hidden; verdicts, scores, extracted values and human decisions are kept. Read each abstract on PubMed via its PMID link.
