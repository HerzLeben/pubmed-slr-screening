- 位置づけ：教育と手法の検証用。PubMed だけを検索し、答えは PMID のある組み入れ研究だけ（eval-2.md「検索の網羅性」）

## 定義

- 検索 Recall：|組み入れ ∩ 全ヒット（`all_pmids`）| / |組み入れ|
- Recall@k：候補を A のスコアの降順（同点は `candidates.json` の rank の昇順）に並べ、上位 k 件に入った組み入れ研究の割合。**分母は「母集団に入った組み入れ研究」**
- 母集団は2通り
  - **全ヒット**：検索で拾った候補だけ（683／698／484件）
  - **原著と同じ作り方**：全ヒットに、検索で拾えなかった組み入れ研究を足したもの。足したのは 37168849 の 28864289 の1件だけ（`fetch_pubmed.py --add-pmid`、最後のバッチに入れ、screener には足したことを渡していない）。31190844 の 22160384・24030379 は新しい検索で拾えたので足していない（DECISIONS 指示書19 3〜4章）。原著は「組み入れ研究をすべて入れた候補」の中で順位を付けている（arXiv HTML 版、DECISIONS に引用）
- 満点：基準の数（31190844 は I1〜I5・E1〜E3 の8、ほかの2本は7）

## 取りこぼしと順位を下げた理由

候補の中の組み入れ研究には、どれも除外（-1）で落とす仕組みが無い（eval-3 は順位だけで評価する）。順位を下げたのは次の -1。

| レビュー | PMID | -1 の基準 | 分類 |
|---|---|---|---|
| 31190844 | 25154820、25319501、25317870、21832238 | I5（比較群がある） | 基準の案が原著の範囲と合わない。案の I5 は「採否は人が決める」とした問いで、人の判断を外した eval-3 では表のまま使った。単群の試験は I5 で -1 になる。候補698件のうち110件が I5 = -1 |
| 31190844 | 24030379 | I3（autologous） | 抄録の記載による（理由の確認は抄録と判定の値から。臨床的な解釈はしない） |
| 37168849 | 30034945、28864289 | I3（CAR-T） | ベンチマークの答えが、元のレビュー自身の基準（CAR-T）と食い違う（eval-2.md「元のレビューとの照合」）。CAR-NK と、CAR を持たない NK 細胞 |
| 37168849 | 33495835 | I3・I4・E2 | 患者のデータが全文にしか無く、抄録では前臨床に見える（eval-2 と同じ） |

- 33746596 は -1 が1件も無く、@20 を外れた3件（29812997 21位、27270177 22位、30396908 33位）は、満点の同点（21件）の並びと、スコア 6 の順位で外れている
- 31190844 の @20 が低いのは、満点 8 に届く候補が無く（最高 7 が15件）、組み入れ研究7件のうち4件が I5 で1点ずつ下がって、スコア 6（45件）の中に入ったため

## 読み取れること（臨床の解釈ではなく、パイプラインの評価として）

1. 人の判断を外しても、検索は 26/27 を拾い、eval-2（人が承認した式、24/27）より高かった。人の承認の段で式に加えた制約が、網羅性を下げていた可能性がある（確かめてはいない）
2. Recall@50 は3本の平均 0.779 で、原著の 0.713 と同じ水準。Recall@20 は平均 0.482 で原著の 0.567 より低い。3本しか無いので、1本（31190844）の値に強く引っ張られる
3. 31190844 の低さは、screener の誤りではなく、基準の案（I5）がそのまま使われたことによる。I5 を外した参考値では @50 が 0.429 → 0.714。**基準を人が直さないと、案の問いがそのまま順位を下げる**。これは人の判断を入れる意味を示す結果でもある（eval-2 では人が I5 を外していた）
4. 33746596 は -1 が1件も無く、差は満点の同点の並び（rank＝relevance 順）で決まった。スコアが合計なので、基準の数が少ないと同点が増える
5. 37168849 の3件の -1 は、eval-2 と同じく、ベンチマークの答えと元のレビューの基準の食い違いによるもの
