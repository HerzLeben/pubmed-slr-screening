# eval-1：最初の並列実行の評価（2026-09-27）

> 人が直した基準と人の判断を含むので、原著との比較には使わない。比較は [eval-3.md](eval-3.md)（2026-09-30）

- 対象：TrialReviewBench の3本（31190844、33746596、37168849）。正解は `bench/reviews.jsonl` の `included_pmids`（7・9・11件）
- 入力：`reviews/<PMID>/search.json`（`all_pmids`＝全ヒット、`pmids`＝固定した上位200件）、`results/screen/{a,b}/`（snap/08-first-parallel）、`results/adjudication/`、`results/human/`（人の判断 17件：組み入れ3・除外14）
- 実行：`python scripts/eval_screening.py`（1行1本の JSON を出す）。数字はすべてこの出力から写した
- レポート：`python scripts/build_report.py --out results/report.html` を再実行。600件、検査の警告 0件、未判断 0件
- `included_pmids` は、このファイルを書く段になって初めて読んだ（判定・裁定・人の判断はすべてその前に終わっている）

## 定義

| 指標 | 定義 |
|---|---|
| 検索 Recall | 組み入れ研究のうち、全ヒット（`all_pmids`）／上位200件（`pmids`）に入った割合。分母は `included_pmids` の全件 |
| Recall@k | 200件を `scripts/rules.py` の `score`（判定値の合計）の降順、同点は `rank` の昇順に並べ、上位 k 件に入った組み入れ研究の割合。分母は「200件に入った組み入れ研究」（原著と同じくスクリーニングだけを測る）。スコアは A だけ・B だけ・A+B の3通り |
| 最終の組み入れ候補 | A だけ：A の overall が include。B だけ：B の overall が include。2体＋裁定＋人：`agreed_include` ＋ 人が include にした `needs_human`（docs/schema.md 8章） |
| Recall（最終） | 最終の組み入れ候補に入った組み入れ研究の割合。分母は全件（検索から通し）と、200件に入ったもの（スクリーニングだけ）の2通り |

- 検索で落ちた3件の理由は、公式 PubMed コネクタで `<PMID>[uid] AND (ブロック)` を投げ、どのブロックで0件になるかで確かめた（2026-09-27）。書誌は PubMed による：22160384 [doi:10.1182/blood-2011-10-384388](https://doi.org/10.1182/blood-2011-10-384388)、24030379 [doi:10.1182/blood-2013-06-506741](https://doi.org/10.1182/blood-2013-06-506741)、28864289 [doi:10.1016/j.jcyt.2017.07.008](https://doi.org/10.1016/j.jcyt.2017.07.008)

## 読み取れること（臨床の解釈ではなく、パイプラインの評価として）

1. 取りこぼしの大半（19件中16件）は **上位200件の枠**。全ヒットでの検索 Recall は 0.714／1.000／0.909 で原著の範囲（0.711–0.834）と同じかそれ以上だが、上位200件に絞ると 0.000／0.333／0.455 に下がる。31190844 は組み入れ研究が1件も200件に入らず、スクリーニングの評価ができない
2. 200件に入った組み入れ研究（8件）は、A・B・2体のどれでも全部拾えており、Recall@20 も 1.000。この範囲では、2体にしたことで取りこぼしは増えも減りもしていない。最終の候補の件数は A だけに比べ 1〜4件減った（48→47、35→33、22→18）。その代わりに人が 5・5・7件を判断した
3. 検索で落ちた3件のうち2件（31190844）は P のブロックの MeSH（"Hematologic Neoplasms" が B 細胞リンパ腫・CLL を含まない）と "B-cell malignancies" の語が原因。1件（37168849 の 28864289）は CAR-T ではない NK 細胞の試験で、ベンチマーク側の組み入れの範囲の問題（検索式では拾えない）
4. 次の評価（eval-2）で決めること：上位 n 件の枠を外す（全ヒットをスクリーニングする、31190844 なら 695件）か広げるか、P のブロックに "B-cell malignancies" や MeSH の Lymphoma／Leukemia を足すか。どちらも人が決める
